AI-Based Workout Assistant

An AI-powered fitness application developed to help users perform exercises with correct posture using computer vision.

Features

- Real-time posture detection
- Automatic repetition counting
- Exercise posture correction feedback
- User exercise tracking

Technologies Used

- Python
- OpenCV
- MediaPipe
- Streamlit
- SQLite
- Machine Learning

Project Objective

This project aims to help people exercise at home with correct posture and real-time feedback through a camera-based system.
